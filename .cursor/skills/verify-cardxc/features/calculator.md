# Calculator

## Sub-features
Amount input, currency/rate selection, fee/result display, target-rate alert UI.

## How to get to it (user POV)
Open `http://127.0.0.1:5000/calculator`.

## Driving it with Cursor computer use
Confirm the calculator heading renders. Enter a harmless test amount such as `1000` in the input with placeholder `1000`; change only display/calculation controls that do not submit money, then capture the updated calculated result.

## Gotchas
This is a calculation/display flow, not a payment action. Do not submit transfers or connect production payment methods while proving calculator behavior.
