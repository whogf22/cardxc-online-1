# Sign up

## Sub-features
Name, email, phone, password entry, password visibility, submit/loading state, validation/error messaging.

## How to get to it (user POV)
Open `http://127.0.0.1:5000/signup` or click `Get Started` from Home.

## Driving it with Cursor computer use
Confirm `Create Your Account` renders. Exercise client-side validation with non-secret dummy values. Only create an account when the environment is explicitly non-production and a disposable test identity is available.

## Gotchas
Do not create real customer accounts, trigger production email/SMS, or use real personal data for verification.
